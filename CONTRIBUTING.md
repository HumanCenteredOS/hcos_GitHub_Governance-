# Contributing to HCOS

Thank you for helping improve the HCOS framework.

## Before Opening a Pull Request

- Follow HCOS naming conventions.
- Update the document version.
- Update the relevant CHANGELOG.
- Review for consistency with related standards.

## Review Checklist

- [ ] Preserves human dignity
- [ ] Recognizes system influences
- [ ] Preserves personal agency
- [ ] Uses clear language
- [ ] States limitations honestly

## Release Policy

No HCOS document should be described as published or approved until:

- Review is complete.
- Changes are committed.
- CHANGELOG has been updated.
- A Git tag has been created.
- A GitHub Release has been published.

See `RELEASE_PROCESS.md`.
